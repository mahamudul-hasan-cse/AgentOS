Short introduction

AIOS (dashboard name AgentOS-Lite) maps textbook OS ideas onto multi-agent LLM workloads. Every meaningful agent–kernel interaction goes through SyscallDispatcher.dispatch. A research→code→test→report pipeline and a kernel assistant exercise that path live; synthetic and real-captured benches evaluate the algorithms honestly — including negative results.
