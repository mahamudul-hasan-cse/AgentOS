# Course portal submission checklist

Portal asks for three things. This project uses the **GitHub repository** as the public project page (not a separate github.io site).

## 1. Technical report (STAR)

- File: [`COURSE_REPORT.md`](COURSE_REPORT.md)
- Challenges use **Situation → Task → Action → Result**
- Before upload: fill **Student ID** at the top (last-minute polish OK)
- If the LMS wants a file: export to **PDF** and upload

## 2. GitHub page link → submit the **repository**

Paste this as the GitHub / project page link:

```
https://github.com/mahamudul-hasan-cse/AIOS
```

The README already includes:

- Short introduction + architecture sketch  
- **Demo video** section (2–5 min) — add your YouTube link after recording  
- Skills table  
- Links to the STAR report and this checklist  

Recording script: [`docs/DEMO_VIDEO_SCRIPT.md`](docs/DEMO_VIDEO_SCRIPT.md)

### After you record the video

1. Upload to YouTube (unlisted is fine).  
2. Put the watch URL (or thumbnail markdown) under **Demo video** in [`README.md`](README.md).  
3. Commit and push `main`.

## 3. GitHub folder

- Same URL: **https://github.com/mahamudul-hasan-cse/AIOS**  
- Or: GitHub → Code → **Download ZIP** if the portal wants a folder upload  

## Suggested portal paste

```
GitHub / project page:  https://github.com/mahamudul-hasan-cse/AIOS
Technical report:       https://github.com/mahamudul-hasan-cse/AIOS/blob/main/COURSE_REPORT.md
GitHub folder:          https://github.com/mahamudul-hasan-cse/AIOS
```

Optional (extra, not required): static site under `docs/` if you later enable Pages.
